# Paradise-Nursery-Shopping-Application
A project submission zone for IBM's Front-End development with react certification

React-based e-commerce application built for houseplant enthusiasts. The app allows users to browse cataloged houseplants organized by category, add items to a dynamic shopping cart using Redux Toolkit, manage quantities, and review total purchasing costs.

## Project Structure

- `src/App.jsx` - Root application routing and landing page view.
- `src/AboutUs.jsx` - Company overview and mission statement component.
- `src/ProductList.jsx` - Plant catalog grid, category organization, and persistent navbar.
- `src/CartSlice.jsx` - Redux Toolkit slice managing cart state (`addItem`, `removeItem`, `updateQuantity`).
- `src/CartItem.jsx` - Shopping cart management interface and itemized cost breakdown.
- `src/App.css` - Custom styling and landing page background image rules.
